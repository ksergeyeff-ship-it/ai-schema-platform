## 📌 О проекте

AI-Schema — это платформа, которая превращает голосовые команды в процессе удаленной рабоы группы в рабочие интерактивные схемы за минуты. Участники удалённо создают, редактируют и синхронизируют схемы голосом, текстом или мышью, а языковая модель (LLM) преобразует намерения в структурированные команды, которые исполняет детерминированный серверный движок.

**Ключевая идея:** LLM отвечает за смысл и топологию, классический код — за точную геометрию и синхронизацию. Это исключает «галлюцинации» нейросети и гарантирует инженерную достоверность.

---

##  Решаемая проблема

- Разрыв между скоростью обсуждения идеи и скоростью её технической фиксации.
- Ручное рисование схем отвлекает от сути совещания.
- Созданные схемы «умирают» после сохранения — для превращения их в рабочий интерфейс нужен отдельный цикл разработки.
- Отсутствие единой среды, где идея мгновенно становится исполняемым активом.

## 🏗️ Архитектура

Система построена по принципу **общей шины** на базе MQTT-брокера:

**Основные компоненты:**
- **Браузерный клиент** — SVG-холст, ввод (микрофон, клавиатура, мышь), чат.
- **ASR** — распознавание речи (голос → текст).
- **LLM Proxy** — прокси к большой языковой модели (GigaChat / Qwen).
- **RAG** — база знаний для валидации и нормативов.
- **Tools Registry** — реестр инструментов (создание узлов, связей, группировка).
- **Graphical Model** — серверная модель схемы (DOM/SVG).
- **Event Emulator** — эмулятор событий для тестирования интерактивности.
- **External Sources** — внешние источники данных (SCADA, PLC, IoT).

## 🛠️ Технологии

- **Frontend:** HTML5, SVG, WebSocket/ МQTT, WebRTC (камера), Web Speech API
- **Backend:** Сервер на базе Spring Boot, MQTT-брокер (Mosquitto / HiveMQ)
- **AI:** LLM (GigaChat / Qwen / OpenAI), ASR (VOSK), RAG
- **Хранение:** PostgreSQL / MongoDB, Redis (кэш)
- **Инфраструктура:** Docker, облачные ресурсы (SberCloud)
